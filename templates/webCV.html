Sobre Mí

Soy un desarrollador que empezó como autodidacta en este mundillo, aunque también estoy cursando DAM (Desarrollo de Aplicaciones Multiplataforma). Me encanta resolver problemas complejos y aprender constantemente nuevas tecnologías.

Mi experiencia abarca desde el desarrollo frontend con HTML, CSS, JavaScript y PHP, y Kotlin para móviles, hasta el backend con Python, Java y bases de datos. También he utilizado librerías como YOLO (visión artificial), FastAPI, Docker, PyQt6, Retrofit y muchas más en distintos proyectos.

Me gusta estar al tanto de las nuevas tecnologías. Me informo a través de creadores como Midudev, MoureDev o Aristidevs. Aunque no da tiempo a aprenderlo todo, me gusta mantenerme informado sobre las últimas novedades.

A día de hoy estoy más enfocado en el desarrollo móvil con Kotlin y Python, especialmente en APIs y YOLO. Creo que lo que más me gusta es el backend —la inteligencia artificial y las APIs— aunque los resultados visuales bonitos con CSS o Three.js también me encantan.

// Proyecto 002

Dashboard Analytics de RTM

JavaScript HTML/CSS MySQL Kotlin Jetpack Compose Retrofit

Descripción

RTM (Real Time Management) es un sistema integral que desarrollé durante mis prácticas en una empresa para controlar y registrar las horas de trabajo de los empleados. El proyecto abarca tanto una aplicación web como una aplicación móvil nativa, ofreciendo una solución completa para la gestión de tiempo y recursos humanos.

Características principales

  • Dashboard Web Interactivo: Visualización en tiempo real de estadísticas con gráficos dinámicos
  • App Móvil Android: Desarrollada con Kotlin y Jetpack Compose para registro de horas on-the-go
  • Exportación a Excel: Generación automática de reportes
  • Sistema Multi-plataforma: Sincronización web-móvil mediante API REST
  • Filtros Avanzados: Búsqueda por empleado, fecha, departamento, etc.

Impacto

Proyecto desarrollado en un entorno empresarial real con requisitos y deadlines concretos. Me permitió integrar múltiples tecnologías, colaborar con el equipo y adaptar el código a sus estándares.

Juego Móvil con Kotlin

Kotlin Jetpack Compose JSON SharedPreferences Navigation Media Player

Descripción

Este proyecto nació como un experimento personal para aprender desarrollo de juegos en Android, pero terminó convirtiéndose en algo mucho más grande. Integra arquitectura MVVM, navegación dinámica, sonido, persistencia local y animaciones fluidas.

Características

  • Navegación Dinámica: Navigation Component con transiciones fluidas entre pantallas
  • Almacenamiento Persistente: SharedPreferences y JSON para guardar progreso
  • Sistema de Sonido: MediaPlayer y SoundPool para efectos y música de fondo
  • UI Moderna: Jetpack Compose con Material Design 3
  • Gestión de Estados: ViewModels y StateFlow

Detección de Objetos con YOLO

Python YOLO OpenCV FastAPI NumPy

Introducción

Mi entrada en el mundo de la visión artificial fue gracias a uno de mis mentores. Me enseñó los fundamentos de YOLO, cómo funciona y cómo implementarlo. Esta tecnología me fascinó por su capacidad de detectar y clasificar objetos en tiempo real.

Proyectos desarrollados

  • Contador de Vehículos: Detección multiclase de coches, camiones, motos y autobuses con tracking y estadísticas en tiempo real
  • Reconocimiento de Alta Fiabilidad: Detección multi-objeto con bounding boxes y porcentajes de confianza
  • API Móvil: FastAPI que recibe imágenes del móvil y devuelve detecciones JSON
  • Piedra-Papel-Tijera con IA 🎮: Reconocimiento de gestos de mano para jugar en tiempo real
