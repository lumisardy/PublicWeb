📋 Sobre Mí

Soy un desarrollador que empezó como autodidacta en este mundillo, aunque también estoy cursando DAM (Desarrollo de Aplicaciones Multiplataforma). Me encanta resolver problemas complejos y aprender constantemente nuevas tecnologías.

Mi experiencia abarca desde el desarrollo frontend, con HTML, CSS, JavaScript y PHP (sé lo básico), y Kotlin (para móviles), hasta el backend con Python, Java y bases de datos. También he utilizado varias librerías en cada uno de estos lenguajes, como YOLO (visión artificial) en Python, FastAPI, Docker, PyQt6, Retrofit para el control de APIs en móvil, y muchas más que he probado para distintos proyectos. No tengo un dominio alto de todas, por ejemplo Flask, que lo uso para gestionar esta web, aunque todavía me queda mucho por aprender de él jaja.

Me gusta estar al tanto de las nuevas tecnologías y de lo que ocurre en el mundillo. Generalmente me informo a través de vídeos de creadores como Midudev, MoureDev o Aristidevs. Aunque no da tiempo a aprender de todo, me gusta mantenerme informado sobre las últimas novedades, además de que me resulta muy interesante.

A día de hoy (12/11/2025), estoy más enfocado en el desarrollo móvil con Kotlin. También trabajo con Python, especialmente en temas de APIs y YOLO. Actualmente estoy aprendiendo Java, ya que lo estoy viendo en clase, pero después de todo, creo que lo que más me gusta es el backend —no tanto las bases de datos, sino aspectos como la inteligencia artificial o las APIs. Aun así, tengo que decir que ver resultados visuales bonitos con CSS o Three.js también me encanta, así que no descarto en un futuro dedicarme también al desarrollo frontend.

Dashboard Analytics de RTM

Real Time Management - Sistema Completo de Gestión de Tiempo

JavaScript HTML/CSS MySQL Kotlin Jetpack Compose Retrofit

📋 Descripción del Proyecto

RTM (Real Time Management) es un sistema integral que desarrollé durante mis prácticas en una empresa para controlar y registrar las horas de trabajo de los empleados. El proyecto abarca tanto una aplicación web como una aplicación móvil nativa, ofreciendo una solución completa para la gestión de tiempo y recursos humanos.

🎯 Características Principales

  • Dashboard Web Interactivo: Visualización en tiempo real de estadísticas y métricas de empleados con gráficos dinámicos
  • Aplicación Móvil: Versión nativa para Android desarrollada con Kotlin y Jetpack Compose para registro de horas sobre la marcha
  • Sistema de Registro Flexible: La información se guarda de manera diferente según los datos introducidos, adaptándose a distintos casos de uso
  • Exportación a Excel: Generación automática de reportes en formato Excel para análisis externo
  • Gráficas y Estadísticas: Visualización avanzada de datos con múltiples tipos de gráficos (barras, líneas, circulares)
  • Sistema Multi-plataforma: Sincronización entre web y móvil mediante API REST

💻 Tecnologías Utilizadas

Frontend Web:

  • HTML5, CSS3 y JavaScript vanilla para la interfaz web
  • Chart.js o similar para visualización de datos
  • Diseño responsive para adaptarse a diferentes dispositivos

Backend y Base de Datos:

  • MySQL para almacenamiento de datos (esquema diseñado por la empresa)
  • API REST para comunicación entre frontend y backend

Desarrollo Móvil:

  • Kotlin como lenguaje principal
  • Jetpack Compose para UI moderna y declarativa
  • Retrofit para consumo de API REST
  • Almacenamiento local para trabajo offline

🔧 Funcionalidades Técnicas

  • Gestión de Sesiones: Sistema de login y autenticación para diferentes niveles de usuario
  • CRUD Completo: Crear, leer, actualizar y eliminar registros de tiempo
  • Filtros Avanzados: Búsqueda y filtrado por empleado, fecha, departamento, etc.
  • Reportes Automáticos: Generación de informes periódicos y personalizables
  • Notificaciones: Sistema de alertas para recordatorios y actualizaciones importantes
  • Optimización de Rendimiento: Carga lazy de datos y paginación para grandes volúmenes

📊 Impacto y Resultados

Este proyecto fue desarrollado durante mis prácticas profesionales y representó un desafío significativo que me permitió:

  • Trabajar en un entorno empresarial real con requisitos y deadlines concretos
  • Integrar múltiples tecnologías en una solución coherente
  • Diseñar interfaces intuitivas tanto para web como para móvil
  • Aprender sobre arquitectura de software y mejores prácticas
  • Colaborar con el equipo de la empresa y adaptar el código a sus estándares

🎓 Aprendizajes Clave

  • Desarrollo full-stack coordinando múltiples plataformas
  • Implementación de API REST y manejo de estados en aplicaciones móviles
  • Diseño de bases de datos relacionales eficientes
  • Experiencia con Jetpack Compose y arquitectura moderna de Android
  • Generación de reportes y exportación de datos
  • Optimización de consultas SQL para mejorar rendimiento

Juego Móvil con Kotlin

Proyecto Experimental de Desarrollo de Juegos Android

Kotlin Jetpack Compose JSON SharedPreferences Navigation Media Player

📋 Descripción del Proyecto

Este proyecto nació como un experimento personal para aprender desarrollo de juegos en Android, pero terminó convirtiéndose en algo mucho más grande. Lo que empezó como una simple prueba se transformó en un proyecto complejo donde invertí muchas horas explorando diferentes aspectos del desarrollo móvil moderno con Kotlin.

El juego integra múltiples tecnologías y patrones de diseño que no solo hacen que funcione, sino que sea escalable y mantenible.

🎮 Características del Juego

  • Sistema de Navegación Dinámica: Implementación avanzada de Navigation Component de Jetpack para transiciones fluidas entre pantallas
  • Almacenamiento Persistente: Uso de SharedPreferences y JSON para guardar progreso del jugador, puntuaciones y configuraciones
  • Sistema de Sonido: Integración de MediaPlayer para efectos de sonido y música de fondo con controles de volumen
  • UI Moderna: Interfaz completamente desarrollada con Jetpack Compose, aprovechando su naturaleza declarativa
  • Gestión de Estados: Manejo complejo de estados del juego usando ViewModels y StateFlow
  • Animaciones Fluidas: Animaciones personalizadas para mejorar la experiencia de usuario

💻 Tecnologías y Librerías Implementadas

Core de Desarrollo:

  • Kotlin: Lenguaje principal con uso de coroutines para operaciones asíncronas
  • Jetpack Compose: Framework moderno de UI declarativa
  • Material Design 3: Componentes y temas de Material You

Arquitectura y Navegación:

  • Navigation Component: Para gestionar el flujo entre pantallas
  • ViewModel: Separación de lógica de negocio de la UI
  • StateFlow/LiveData: Para observar cambios de estado reactivamente

Persistencia de Datos:

  • SharedPreferences: Para almacenar configuraciones y datos simples
  • JSON Serialization: Para estructuras de datos más complejas
  • DataStore (posiblemente): Como alternativa moderna a SharedPreferences

Multimedia:

  • MediaPlayer: Reproducción de audio y efectos de sonido
  • SoundPool: Para efectos de sonido cortos y frecuentes

🔧 Desafíos Técnicos Superados

  • Gestión de Memoria: Optimización para evitar memory leaks con audio y recursos gráficos
  • Ciclo de Vida: Manejo correcto del ciclo de vida de Android para pausar/reanudar el juego
  • Navegación Compleja: Implementación de un sistema de navegación con múltiples rutas y argumentos
  • Serialización de Datos: Conversión eficiente entre objetos Kotlin y JSON
  • Threading: Uso de coroutines para operaciones que no bloquean la UI
  • Estado Global: Mantener el estado del juego consistente a través de diferentes pantallas

🎯 Funcionalidades Implementadas

  • Sistema de Puntuación: Guardado automático de mejores puntuaciones y estadísticas
  • Configuración Personalizable: Opciones para ajustar volumen, dificultad y preferencias visuales
  • Pantallas Múltiples: Menú principal, pantalla de juego, configuración, puntuaciones, etc.
  • Feedback Visual y Auditivo: Respuestas inmediatas a las acciones del jugador
  • Sistema de Guardado: Capacidad de guardar y cargar partidas
  • Responsive Design: Adaptación a diferentes tamaños de pantalla

📊 Aprendizajes y Evolución

Este proyecto fue especialmente valioso porque:

  • Me permitió profundizar en Jetpack Compose más allá de lo básico
  • Aprendí sobre la arquitectura MVVM aplicada a juegos móviles
  • Desarrollé habilidades en optimización de rendimiento para aplicaciones intensivas
  • Comprendí mejor el ciclo de vida de Android y sus implicaciones
  • Experimenté con diferentes patrones de diseño y arquitecturas
  • Mejoré mis habilidades de debugging y resolución de problemas complejos

Lo que empezó como un simple experimento se convirtió en un proyecto donde invertí muchas horas perfeccionando cada detalle, y eso es precisamente lo que lo hace valioso: el aprendizaje profundo que obtuve en el proceso.

🎓 Impacto en mi Desarrollo Profesional

  • Consolidé mi conocimiento de Kotlin como lenguaje principal
  • Me familiaricé con el ecosistema completo de Android moderno
  • Aprendí a gestionar proyectos complejos de principio a fin
  • Desarrollé capacidad para resolver problemas creativamente
  • Mejoré mis habilidades de UI/UX en desarrollo móvil

Detección de Objetos con YOLO

Sistemas de Visión Artificial para Múltiples Aplicaciones

Python YOLO OpenCV FastAPI NumPy Computer Vision

📋 Introducción al Proyecto

Mi entrada en el mundo de la visión artificial fue gracias a uno de mis mentores que se dedica profesionalmente a este campo. Me enseñó los fundamentos de YOLO (You Only Look Once), cómo funciona, qué se puede hacer con él y cómo implementarlo de manera efectiva.

Esta tecnología me fascinó inmediatamente por su capacidad de detectar y clasificar objetos en tiempo real, y desde entonces he desarrollado múltiples proyectos explorando diferentes aplicaciones prácticas de la visión artificial.

🎯 Proyectos Desarrollados

1. Contador de Vehículos en Autovía

Sistema de conteo automático de vehículos en carreteras y autopistas:

  • Detección Multiclase: Capacidad de distinguir entre coches, camiones, motos y autobuses
  • Tracking de Objetos: Seguimiento de vehículos para evitar contar el mismo vehículo múltiples veces
  • Líneas Virtuales: Sistema de conteo basado en líneas virtuales que detectan cuando un vehículo las cruza
  • Estadísticas en Tiempo Real: Generación de datos sobre flujo de tráfico, velocidad promedio y densidad
  • Exportación de Datos: Registro de datos para análisis posterior

2. Reconocimiento de Objetos de Alta Fiabilidad

Sistema robusto de detección y clasificación de objetos con múltiples casos de uso:

  • Detección Multi-objeto: Capacidad de detectar y clasificar simultáneamente diferentes tipos de objetos
  • Alta Precisión: Optimización del modelo para minimizar falsos positivos y negativos
  • Procesamiento en Tiempo Real: Análisis de video en streaming con baja latencia
  • Bounding Boxes y Labels: Visualización clara de objetos detectados con porcentajes de confianza

3. Sistema de Reconocimiento con API Móvil

Integración de visión artificial con aplicaciones móviles mediante API:

  • API REST con FastAPI: Servidor que recibe imágenes y devuelve detecciones
  • Procesamiento de Imágenes: Análisis de fotos tomadas desde el móvil
  • Respuesta JSON: Formato estructurado con información de objetos detectados
  • Optimización para Móvil: Compresión de imágenes y respuestas rápidas

4. Juego de Piedra, Papel o Tijera con IA 🎮

Proyecto divertido que usa visión artificial para jugar piedra, papel o tijera:

  • Detección de Gestos: Reconocimiento de manos y clasificación del gesto mostrado
  • Lógica de Juego: Sistema que determina el ganador automáticamente
  • Interfaz Interactiva: Feedback visual en tiempo real
  • Contador de Puntuación: Sistema de seguimiento de partidas ganadas/perdidas

💻 Stack Tecnológico

Detección y Procesamiento:

  • YOLO (YOLOv5/v8): Modelo principal de detección de objetos
  • OpenCV: Procesamiento de imágenes y video, manipulación de frames
  • NumPy: Operaciones numéricas y manipulación de arrays
  • PIL/Pillow: Procesamiento adicional de imágenes

Backend y API:

  • FastAPI: Framework moderno para crear APIs REST
  • Uvicorn: Servidor ASGI de alto rendimiento
  • Pydantic: Validación de datos y serialización

Optimización:

  • CUDA/GPU: Aceleración por hardware cuando está disponible
  • Threading: Procesamiento paralelo para mejor rendimiento
  • Caching: Optimización de modelos cargados en memoria

🔧 Implementación Técnica

Pipeline de Procesamiento:

  • Captura: Obtención de frames desde cámara o video
  • Preprocesamiento: Redimensionamiento y normalización de imágenes
  • Inferencia: Paso de imagen por el modelo YOLO
  • Post-procesamiento: Filtrado de detecciones por confianza, NMS (Non-Maximum Suppression)
  • Visualización: Dibujado de bounding boxes y labels
  • Análisis: Extracción de métricas y estadísticas

📊 Desafíos y Soluciones

  • Rendimiento en Tiempo Real: Optimización del modelo y uso de GPU para mantener FPS altos
  • Falsos Positivos: Ajuste de thresholds de confianza y filtrado inteligente
  • Tracking Preciso: Implementación de algoritmos de tracking para seguimiento consistente
  • Iluminación Variable: Preprocesamiento adaptativo para diferentes condiciones de luz
  • Escalabilidad: Diseño de API que puede manejar múltiples peticiones concurrentes
  • Oclusión de Objetos: Manejo de situaciones donde objetos se superponen

🎓 Conocimientos Adquiridos

  • Deep Learning: Entendimiento de redes neuronales convolucionales y su funcionamiento
  • Arquitecturas YOLO: Conocimiento de diferentes versiones y sus trade-offs
  • Optimización de Modelos: Técnicas para mejorar velocidad sin sacrificar precisión
  • APIs de IA: Diseño de endpoints para servir modelos de machine learning
  • Integración Multiplataforma: Conexión entre sistemas de IA y aplicaciones móviles
